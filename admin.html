Opzionale – colonna ruoli in Supabase
Per salvare i ruoli Scorer / Caposquadra (oltre al flag is_admin), esegui in SQL Editor: 
alter table profiles add column if not exists role text default 'socio';
update profiles set role = 'admin' where is_admin = true;
Senza questa colonna il pannello continua a funzionare con is_admin.
